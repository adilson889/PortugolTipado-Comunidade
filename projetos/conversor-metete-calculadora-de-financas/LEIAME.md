# Conversor Metete

O **Conversor Metete** é um projeto de nível iniciante concebido para ensinar a entrada de dados, verificação de tipos e estruturas condicionais em PortugolTipado.

## O que vais aprender:
- Declaração estrita de tipos (`real`, `inteiro`, `texto`).
- Leitura e validação de dados do utilizador.
- Estruturas condicionais (`se`, `senao`).
- Formatação de saída limpa no terminal.

## Como executar:
Compila o ficheiro `principal.port` no editor.
