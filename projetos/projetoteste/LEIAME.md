# Sistema de alunos

> Projeto de exemplo para ensinar **estruturas** e *funções* em PortugolTipado.

## Sobre

Este projeto regista alunos, calcula a média e mostra um relatório simples no ecrã. Serve para praticar `inteiro`, `real` e `texto`.

## Funcionalidades

- Cadastro de alunos com nome e notas
- Cálculo da média
- Relatório final no ecrã

## Como usar

1. Descarrega o projeto
2. Abre o ficheiro `principal.port`
3. Carrega em executar

## Exemplo

```
funcao inicio()
{
    inteiro idade = 16
    real media = 9.5
    escreva("Ola, mundo!\n")
}
```

## Tipos usados

| Tipo | Exemplo | Descrição |
|------|---------|-----------|
| inteiro | 16 | Números sem casas decimais |
| real | 9.5 | Números com casas decimais |
| texto | "Ana" | Palavras e frases |
| logico | verdadeiro | Verdadeiro ou falso |

## Ficheiros

- `principal.port`: ponto de entrada
- `alunos.port`: funções do cadastro

Mais informação no [repositório](https://github.com/adilson889/PortugolTipado).
